# WxkbToolbar10

微信输入法键盘扩展（`com.tencent.wetype.keyboard` / `wxkb_plugin`）增强插件。

## 功能

### 设置面板（设置 → 微信输入法增强）

**工具栏功能**
- **功能排序与显隐**：拖动排序、左滑隐藏；移除的功能会从键盘工具栏上消失。
  - 分组一「键盘内可用」：语音转文字、表情、常用语、边写边译、手写找字、单手模式、
    键盘调节、键盘选择、繁体输入、定制工具栏、剪贴板。
  - 分组二「需微信主 App」：小程序、灵动表达、问 AI、字体滤镜、排版成图、文字整理。
    **这几项由主 App 处理，键盘扩展进程里点了不会有任何反应**，所以默认不显示，
    并在名称后标注「（无反应）」—— 1.5.x 把它们混在一起，导致用户以为插件坏了。
- **编辑增强按钮**：工具栏尾部追加一排常用编辑按钮，可排序、可单独显隐：
  光标左移 / 光标右移 / 全选 / 剪切 / 粘贴 / 全删 / 剪贴板历史 / 快捷短语 /
  收起键盘 / 切换输入法。

**键盘背景**
- 纯色 / 相册图片（按键盘比例自动裁剪）/ 背景透明度。
- **整键盘透明**：递归清掉键盘自带的背景层（含 `UIVisualEffectView`、铺满型背景图、
  键盘窗口自身），透出后面的内容。**按键底色与按键文字色不受影响，默认仍是黑字。**
  关闭时自动还原原始颜色。

**按键配色**
- 四组底色（字母 / 左侧功能键 / 右侧功能键 / 空格）+ 按键文字色 + 按下高亮色，
  全部用系统取色器选色。
- 字母键支持 A→Z 渐变，以及 26 个字母逐个单独上色。

**按键形状**
- 按键圆角 0 ~ 22 pt。

### 工具栏布局
- 图标保持**原生尺寸**，不自动缩小
- 图标超出可视宽度时**横向滑动**，不挤成一团
- 工具栏**紧贴左侧微信 logo 铺满整行**，消除 logo 与第一个图标之间的空白
- 进入「定制工具栏」编辑态时不强制撑满，避免与原生编辑界面重叠

### 1.6.0 修的三个问题

| 问题 | 根因 | 修法 |
|---|---|---|
| 按键圆角改了没效果 | 原生每次按键状态切换（highlighted / 主题刷新）都会在**背景视图自己的 layout** 里把 `cornerRadius` 写回固定值，把用户设置覆盖了。1.5.x 只在 `WBKeyView.layoutSubviews` 里改一层 subviews | 递归下探定位真正画背景的叶子视图（跳过 `UIImageView`/`UILabel`/`UIButton`），并加**下一轮 runloop 补刀**（`dispatch_async` 再扫一遍全树），盖过原生的最后一次写入 |
| 整体键盘透明没效果 | 只在 `WBRootInputView` 插了一层背景，但键盘自身那些不透明背景层仍在上面挡着 | 递归清除整棵键盘视图树的背景色 / 毛玻璃 / 铺满型背景图，并把键盘窗口本身设为透明；原值用关联对象存着，关闭时精确还原。按键子树完全不动 |
| 部分原生功能点了没反应 | 「小程序 / 灵动表达 / 问 AI / 字体滤镜 / 排版成图 / 文字整理」由微信**主 App** 处理，键盘扩展进程里必然无响应 | 单独分组 + 名称标注「（无反应）」，默认不显示；同时提供上面那排**真正能用的**编辑增强按钮 |

### 编辑增强按钮的架构

键盘扩展跑在**独立沙盒进程**里，够不到宿主 App 的 `firstResponder`，所以
「全选 / 剪切 / 粘贴 / 全删 / 收起键盘」光靠键盘扩展点了必然没反应。
本插件拆成两个 dylib：

- `WxkbToolbar10` — 注入键盘扩展（`wxkb_plugin`），负责背景/配色/圆角/工具栏，
  以及渲染按钮那一排。
- `WxkbToolbar10Host` — 注入普通 App，只在 `%ctor` 里注册 Darwin 通知监听，
  负责执行需要宿主响应的动作。明确排除 `SpringBoard` / `Preferences` / `wxkb_plugin`，
  且只在 App 处于 `active` 状态时才动手，避免误清后台 App 的输入框。

能在扩展内自己做的（光标左右移动、全删、切换输入法）直接走 `UITextDocumentProxy` /
`advanceToNextInputMode`，不经 Darwin 通知，响应更快。

## 适用环境

- iPhone 12 Pro / iOS 16.6
- Relaxin rootless 越狱（ElleKit / TweakInject）
- 依赖 `mobilesubstrate`（ElleKit 提供）、`preferenceloader`

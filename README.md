# WxkbToolbar10

微信输入法键盘扩展（`com.tencent.wetype.keyboard` / `wxkb_plugin`）增强插件。

## 功能

### 设置面板（设置 → 微信输入法增强）

**工具栏功能（由微信原生「定制工具栏」管理）**
- 工具栏上**显示哪些图标、左右顺序**，直接在微信输入法里**长按工具栏进入「定制工具栏」**增删 / 排序即可，**不用进系统设置**。
- 本插件不再接管工具栏功能列表（之前的「功能显隐」面板已移除）：那样做图标和名字对不上微信真图标，且强改按钮位置曾导致键盘扩展崩溃（1.6.16）。
- 插件只负责**外观**：背景 / 整键盘透明 / 按键配色 / 圆角 / 位移，以及工具栏「紧贴左侧 logo 铺满整行 + 不缩小 + 横滑」的布局修复。

**键盘背景**
- 纯色 / 相册图片（按键盘比例自动裁剪）/ 背景透明度。
- **整键盘透明**：递归清掉键盘自带的背景层（含 `UIVisualEffectView`、铺满型背景图、
  键盘窗口自身），透出后面的内容。**按键底色与按键文字色不受影响，默认仍是黑字。**
  关闭时自动还原原始颜色。

**按键配色**
- 四组底色（字母 / 左侧功能键 / 右侧功能键 / 空格）+ 按键文字色 + 按下高亮色，
  全部用系统取色器选色。
- 字母键支持 A→Z 渐变，以及 26 个字母逐个单独上色。
- **内置皮肤（彩虹按键）**：来自百度输入法导出的真·键帽图，开启后把键盘渲染成彩虹键帽
  （替代旧版程序生成的彩虹色），关闭则恢复普通按键配色。
- **配色预设（一键套用）**：极光 / 莫兰迪 / 暗夜 / 清新 四套协调配色，点一下即套用，
  套用后仍可在上方逐项微调。

**按键形状**
- **默认圆角**：按键圆角 0 ~ 22 pt（滑块）。
- **圆形 / 六边形 / 水珠**：在「默认圆角」之外新增三种形状，直接把按键裁成对应形状。
  形状只用图层蒙版裁剪背景，**不动键盘布局**，曾导致键盘崩溃的「改按钮位置」与此无关。

### 工具栏布局
- 图标保持**原生尺寸**，不自动缩小
- 图标超出可视宽度时**横向滑动**，不挤成一团
- 工具栏**紧贴左侧微信 logo 铺满整行**，消除 logo 与第一个图标之间的空白
- 进入「定制工具栏」编辑态时不强制撑满，避免与原生编辑界面重叠

### 1.6.0 修的三个问题

| 问题 | 根因 | 修法 |
|---|---|---|
| 按键圆角改了没效果 | 原生每次按键状态切换（highlighted / 主题刷新）都会在**背景视图自己的 layout** 里把 `cornerRadius` 写回固定值，把用户设置覆盖了。1.5.x 只在 `WBKeyView.layoutSubviews` 里改一层 subviews | 递归下探定位真正画背景的叶子视图（跳过 `UIImageView`/`UILabel`/`UIButton`），并加**下一轮 runloop 补刀**（`dispatch_async` 再扫一遍全树），盖过原生的最后一次写入 |
| 整体键盘透明没效果 | 只在 `WBRootInputView` 插了一层背景，但键盘自身那些不透明背景层仍在上面挡着 | 递归清除整棵键盘视图树的背景色 / 毛玻璃 / 铺满型背景图，并把键盘窗口本身设为透明；原值用关联对象存着，关闭时精确还原。按键子树完全不动 |
| 部分原生功能点了没反应 | 「小程序 / 灵动表达 / 问 AI / 字体滤镜 / 排版成图 / 文字整理」由微信**主 App** 处理，键盘扩展进程里必然无响应 | 单独分组 + 名称标注「（无反应）」，默认不显示 |

> 注：1.6.13 起已**移除「编辑增强按钮」**（那排全选/剪切/粘贴/光标/全删/剪贴板/短语/
> 收起/切换输入法）。原因：要把它无遮挡地插进候选栏与字母键之间，必须撑高键盘窗口，
> 而键盘窗口总高度由系统与微信输入法控制，插件强改 frame 会被微信布局引擎反噬导致错乱，
> 实测无法稳定实现。插件回归为纯**外观**增强（背景 / 整键盘透明 / 按键配色 / 圆角 / 位移）。

## 适用环境

- iPhone 12 Pro / iOS 16.6
- Relaxin rootless 越狱（ElleKit / TweakInject）
- 依赖 `mobilesubstrate`（ElleKit 提供）、`preferenceloader`

## 版本

- 1.8.0 — 深度优化立体键帽（电脑键盘风）：① 整颗键帽外圈一圈近黑硬描边；② 穹顶四周露出
  大幅去饱和的中性深色裙边（上亮下暗渐变），左/右/上/下四面侧壁全部可见，替代旧版大面积
  同色前脸；③ 穹顶高光带加宽（顶部近白）+ 底部上抬加多（前脸更高）+ 顶面圆角随轮廓走。
  参照百度「彩虹按键」皮肤键帽 + 电脑键盘实体键帽观感，全图层渲染、零图片依赖。
- 1.7.5 — 穹顶立体感改由「立体键帽渲染器」实现，功能键白帽 + 键盘背景画布色：
  - **贴图路线退役**：带透明的皮肤切片在真机上从未渲染成功（1.7.2 悬空、
    1.7.3/1.7.4 premultiplied 都修了依旧空白），改用真机上一直稳定渲染的
    立体键帽渲染器（CAShapeLayer+渐变）：底色取皮肤键面代表色，高光/亮面/
    侧壁/投影全部自动推导——效果即 demo 的穹顶键帽，零图片依赖。
  - **功能键黑色之谜破案**：key26a 第 27 格实测是空白画布而非白色键帽——
    1.7.3 全白（画布色被当面色）、1.7.4 全黑（清零 RGB 后面色变纯黑）互为
    证据。现在功能键直接涂画布白，配深灰文字（demo 同款白帽深字）。
  - **键盘背景涂画布色**：皮肤模式自动把键盘底板涂成画布白 (245,247,250)，
    键帽浮在浅色底上；顶栏 tint 同步改深灰保证图标可见。
  - **文字颜色**：非字母键（白帽）→ 深灰；字母键（彩帽）→ 用户设置色。
- 1.7.4 — 穹顶贴图「从未显示」的真正根因修复 + 底色退回彩虹面色：
  - **非法 premultiplied 数据（真根因）**：1.7.2/1.7.3 抠图时只把 alpha 置 0、
    RGB 保留画布色 (245,247,250)，产出「RGB > alpha」的非法 premultiplied 像素，
    GPU 渲染结果是未定义的——真机上整张贴图渲染成空白。1.7.1 的不透明切片
    能显示恰好反证了这一点（内存悬空 bug 是 1.7.2 的次要问题，1.7.3 已修）。
    现在抠掉的像素 RGB 与 alpha 一并清零，数据合法。
  - **底色恒返回键面代表色**：1.7.3 在贴图可用时返回画布色，贴图一空白键盘
    就变成一片惨白（用户截图）；改回面色后，即使贴图再出问题键盘也仍是正确
    的彩虹配色（像切换主题一样），贴图正常时穹顶盖在面色之上、透明边缘露
    同色系，视觉无缝。画布色方案废弃。
- 1.7.3 — 修复 1.7.2 穹顶贴图「消失」，功能键换白色键帽，对齐百度原版效果：
  - **致命内存 bug（穹顶消失的根因）**：1.7.2 的 `WXKBKeycapStrip` 在
    `CGBitmapContextCreateImage` 之后手动 `free()` 了像素缓冲——写时复制只跟踪
    「通过 context 的写入」，不管手动 free → CGImage 数据悬空 → 真机上贴图渲染
    成一片空白，只剩底色平涂（1.7.2 的透明画布「生效」其实是因为图层啥也没画）。
    现改用 `CGDataProviderCreateWithData` 持有缓冲，图片释放时才回收。
  - **功能键换白色键帽**：key26a 实际有 27 格，第 27 格是白色功能键帽（实测确认，
    百度原版 QWERTY 的 123/中英/句号/回车就是它），不再用 key9a 彩色键帽哈希上色。
  - **底色改画布色** `(245,247,250)`：键帽穹顶浮在画布色上，贴图四角的抗锯齿
    过渡与底色无缝衔接（四角白点消失），与百度原版键盘一致；
    贴图缺失的键退回键面代表色，键盘保持彩色。
  - **切片改全高**（key26a 110→132、key9a 122→144）：保留键帽下方柔和投影，
    立体感与百度原版一致。

- 1.7.2 — 皮肤键帽「立体穹顶」修复：把皮肤条里的画布底色抠成透明。
  - 1.7.1 贴上去的切片四周带着皮肤自带的浅灰画布（实测 (245,247,250)），
    在暗色键盘上每颗键周围出现一圈「白边」，且键帽立体感被平涂底色盖住。
  - 现在加载皮肤条时先做**边界泛洪抠图**（从条带四边 BFS，凡与边界连通的
    「中性亮灰」像素 alpha→0）：画布是无色偏中性灰(通道差≤5)，键帽顶面再淡
    也有色偏(实测 26+9 颗全部通道差≥15)，按通道差判据最淡的 V 键也不会被误删；
    键帽黑描边天然挡住泛洪，穹顶造型完整保留。
  - 切片高度 key26a 调到 110px，把键帽底部的黑色描边完整包进键帽本体。
  - 效果：每颗键 = 原生键被皮肤色整体染色 + 皮肤穹顶键帽（顶部亮面/深色侧裙/
    黑描边）叠加其上，立体键帽造型与百度官方 demo 一致，且任何背景色都无缝。

- 1.7.1 — 修正皮肤「贴图错位」：按 PNG 里的真实键距切片 + 按键盘行取色：
  - 实测 key26a.png 是 26 颗键帽、间距恰好 **80px**（尾部还留了 80px 空白，27×80=2160），
    原来按 2160/26≈83 等分，每片多带 3px 隔壁键帽 → 每颗键右侧一条错色竖纹；
    现在按 80px 精确切片，并裁掉键帽下方的柔和投影（key26a 裁到 109px、key9a 裁到 122px），
    键底不再被压出一条浅灰带。
  - 配色改为按 **键盘行** 取片：26 片的颜色分 10/9/7 三段（正好 QWERTY 三行的键数，
    每段自成一条彩虹），原来按字母表序号取片导致整片颜色错位。
  - 皮肤颜色现在同时走原生按键底色通道（直接把每颗键染成皮肤那颗键的颜色），
    所以连原生键框一起被染色，键帽图只负责立体明暗 —— 位置天然对齐，不再有白边割裂。

- 1.7.0 — 内置「彩虹按键」皮肤（替代旧版程序生成的彩虹色）：
  - 把百度输入法导出的真·键帽 PNG（key26a = 26 字母键帽横排、key9a = 9 功能键帽横排）随包内置，
    开启「皮肤 → 启用彩虹按键皮肤」后，把微信键盘每个键渲染成对应彩虹键帽图（图片缺失时退回彩虹配色兜底）。
  - **移除**旧版「彩虹键盘（A→Z 全色）」开关、「彩虹样式（马卡龙）」选项，以及「彩虹 / 键帽粉彩」
    两套配色预设——统一由这套真实皮肤接管彩虹观感。
  - 皮肤图随 tweak 包安装到 /Library/Application Support/WxkbToolbar10/skins/rainbow/res/，
    tweak 在键盘扩展进程里从 jbroot 读取并贴到键背景叶上；立体键帽在皮肤开启时自动让位。

- 1.6.23 — 立体键帽「重做成像真键帽」（用户反馈 1.6.22 仍不像键盘）：
  - 不再只画底部一条暗带，而是把每颗键渲染成一颗真实键帽：深色**键体**（侧壁+前脸）
    铺满轮廓，内部**内缩一圈凸起顶面**（上亮下暗穹顶渐变），底面再抬高露出更明显的**前脸**。
  - 整颗键在 v 上投一道柔和阴影（offset 2 / radius 3 / opacity 0.28）→ 像浮在底板上。
  - 正下方仍伸 4pt 侧壁，给有空隙/透明键盘时的真实厚度。
  - 图层全部挂在背景叶上（避免被叶遮挡），坐标按叶尺寸生成；关闭时清掉三层并还原阴影。

- 1.6.22 — 立体键帽修正（用户反馈「立体感不强 + 没设圆角但角上有灰影」）：
  - **圆角灰影根因**：旧侧壁路径是「拉长的圆角矩形」（高度 +3.5pt、圆角不变），侧壁在
    按键圆角处会比本体宽出一截，看起来就是角上挂灰。改为**同轮廓路径整体下移**，侧边
    与按键完全重合，任何圆角/形状下都不会再外扩。
  - **侧壁颜色改用 HSB**：保色相、亮度约砍半、饱和度加深——粉彩键的侧壁是同色系深色，
    不再是直乘 0.6 出来的灰。
  - **厚度 3.5pt → 5pt**，立体感更明显；取消按键裁剪时同时压掉系统原生阴影，避免漏出灰圈。

    水珠形状下侧壁跟随形状。
  - **马卡龙彩虹**：彩虹键盘新增「样式」选择（标准高饱和 / 马卡龙粉彩），数字键 1-0 也纳入
    彩虹按数字顺序取色。
  - 新增配色预设「**键帽粉彩**」：马卡龙彩虹 + 立体键帽 + 白色功能键，仿机械键盘粉彩键帽
    皮肤观感；其余预设固定 KEYCAP3D=关，保证预设之间切换结果确定。

# WxkbToolbar10

微信输入法键盘扩展（`com.tencent.wetype.keyboard` / `wxkb_plugin`）工具栏增强插件。

## 功能
- 把「定制工具栏」控制中心里提供的**全部功能**补进工具栏（与 App 自带功能取并集），
  当前包含：语音转文字、表情、常用语、边写边译、小程序、手写找字、单手模式、键盘调节、
  键盘选择、繁体输入、定制工具栏、灵动表达、剪贴板、问 AI、字体滤镜、排版成图、文字整理
- 图标保持**原生尺寸**，不再自动缩小
- 图标超出可视宽度时**横向滑动**选取，左右滑动即可取用，不再挤成一团
- 工具栏**紧贴左侧微信 logo 铺满整行**，消除 logo 与第一个图标之间的空白（该空白无法滑入）
- 仍可长按图标进入「定制工具栏」拖拽排序

## 适用环境
- iPhone 12 Pro / iOS 16.6
- Relaxin rootless 越狱（ElleKit / TweakInject）
- 依赖 `mobilesubstrate`（ElleKit 提供）

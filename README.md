# WxkbToolbar10

微信输入法键盘扩展（`com.tencent.wetype.keyboard` / `wxkb_plugin`）增强插件。

## 功能

### 设置面板（设置 → 微信输入法增强）
- **工具栏功能排序与显隐**：进入后拖动排序、左滑隐藏；被移除的功能会从键盘工具栏上消失。
  默认只启用键盘扩展内确认可用的功能（语音转文字、表情、常用语、边写边译、手写找字、
  单手模式、键盘调节、键盘选择、繁体输入、定制工具栏、剪贴板），
  其余「需主 App」的功能默认关闭，可自行加回。
- **键盘背景**：纯色 / 设备上的本地图片，支持透明度调节。
- **按键配色**：字母键底色、功能键底色、按键文字色、按下高亮色（预设 + `#RRGGBB` 自定义）。

改动后收起键盘再弹出即可生效（面板会同时尝试实时通知键盘扩展）。

### 工具栏布局
- 图标保持**原生尺寸**，不再自动缩小
- 图标超出可视宽度时**横向滑动**选取，不再挤成一团
- 工具栏**紧贴左侧微信 logo 铺满整行**，消除 logo 与第一个图标之间的空白
- 进入「定制工具栏」编辑态时不再强制撑满，避免与原生编辑界面重叠

## 适用环境
- iPhone 12 Pro / iOS 16.6
- Relaxin rootless 越狱（ElleKit / TweakInject）
- 依赖 `mobilesubstrate`（ElleKit 提供）、`preferenceloader`

# WxkbToolbar10

微信输入法键盘扩展（`com.tencent.wetype.keyboard` / `wxkb_plugin`）增强插件。

## 功能

### 设置面板（设置 → 微信输入法增强）

**工具栏功能**
- **功能显隐**：进入「功能显隐」后，每个功能都是一行原生开关（iOS 设置里那种按钮），
  想显示哪个就把它打开，关闭的会从键盘工具栏上移除。**全部列出来，按哪个开哪个。**
  - 分组一「键盘内可用（开启即显示在工具栏）」：语音转文字、表情、常用语、边写边译、
    手写找字、键盘调节、键盘选择、繁体输入、定制工具栏、剪贴板。
  - 分组二「需微信主 App（开启也不会显示）」：小程序、单手模式、灵动表达、问 AI、
    字体滤镜、排版成图、文字整理。这几项由微信主程序处理，
    **键盘扩展进程里点了不会有任何反应**，所以开启也不会显示在工具栏，仅供查看。
  - **顺序与对应**：分组一的列表**从上到下 = 微信键盘工具栏从左到右**，每行前面的
    数字就是它在工具栏上的顺位（关闭的功能不占顺位）。轻点右上角「**排序**」进入
    拖动模式，即可调整本组功能在**设置面板里**的上下顺序与顺位编号；「完成」退出。
    **注意**：面板内的拖动排序目前只改变设置里的显示顺序与顺位编号，
    **不会**改变键盘工具栏上图标的实际左右位置。原因：1.6.16 曾在微信排版完成后
    强行把 `WBToolBarButton` 按自定义顺序重排 x 位置，但该改动触发了微信键盘扩展的
    布局异常，导致扩展崩溃（呼出即跳回系统输入法），1.6.17 已回退此功能。键盘内真正
    按自定义顺序重排，需先通过真机 frida 探针确认微信存功能码的确切字段、并规避其
    布局/命中测试假设后才能再做。

**键盘背景**
- 纯色 / 相册图片（按键盘比例自动裁剪）/ 背景透明度。
- **整键盘透明**：递归清掉键盘自带的背景层（含 `UIVisualEffectView`、铺满型背景图、
  键盘窗口自身），透出后面的内容。**按键底色与按键文字色不受影响，默认仍是黑字。**
  关闭时自动还原原始颜色。

**按键配色**
- 四组底色（字母 / 左侧功能键 / 右侧功能键 / 空格）+ 按键文字色 + 按下高亮色，
  全部用系统取色器选色。
- 字母键支持 A→Z 渐变，以及 26 个字母逐个单独上色。

**按键形状**
- 按键圆角 0 ~ 22 pt。

### 工具栏布局
- 图标保持**原生尺寸**，不自动缩小
- 图标超出可视宽度时**横向滑动**，不挤成一团
- 工具栏**紧贴左侧微信 logo 铺满整行**，消除 logo 与第一个图标之间的空白
- 进入「定制工具栏」编辑态时不强制撑满，避免与原生编辑界面重叠

### 1.6.0 修的三个问题

| 问题 | 根因 | 修法 |
|---|---|---|
| 按键圆角改了没效果 | 原生每次按键状态切换（highlighted / 主题刷新）都会在**背景视图自己的 layout** 里把 `cornerRadius` 写回固定值，把用户设置覆盖了。1.5.x 只在 `WBKeyView.layoutSubviews` 里改一层 subviews | 递归下探定位真正画背景的叶子视图（跳过 `UIImageView`/`UILabel`/`UIButton`），并加**下一轮 runloop 补刀**（`dispatch_async` 再扫一遍全树），盖过原生的最后一次写入 |
| 整体键盘透明没效果 | 只在 `WBRootInputView` 插了一层背景，但键盘自身那些不透明背景层仍在上面挡着 | 递归清除整棵键盘视图树的背景色 / 毛玻璃 / 铺满型背景图，并把键盘窗口本身设为透明；原值用关联对象存着，关闭时精确还原。按键子树完全不动 |
| 部分原生功能点了没反应 | 「小程序 / 灵动表达 / 问 AI / 字体滤镜 / 排版成图 / 文字整理」由微信**主 App** 处理，键盘扩展进程里必然无响应 | 单独分组 + 名称标注「（无反应）」，默认不显示 |

> 注：1.6.13 起已**移除「编辑增强按钮」**（那排全选/剪切/粘贴/光标/全删/剪贴板/短语/
> 收起/切换输入法）。原因：要把它无遮挡地插进候选栏与字母键之间，必须撑高键盘窗口，
> 而键盘窗口总高度由系统与微信输入法控制，插件强改 frame 会被微信布局引擎反噬导致错乱，
> 实测无法稳定实现。插件回归为纯**外观**增强（背景 / 整键盘透明 / 按键配色 / 圆角 / 位移）。

## 适用环境

- iPhone 12 Pro / iOS 16.6
- Relaxin rootless 越狱（ElleKit / TweakInject）
- 依赖 `mobilesubstrate`（ElleKit 提供）、`preferenceloader`

## 构建

由 GitHub Actions（macOS + Theos）自动编译，产物推送至越狱源：

https://yzdmm2024.github.io/repo/

```bash
python build/check.py   # 需要 LLVM 18 + iPhoneOS16.5 SDK
```

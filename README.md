# WxkbToolbar10

微信输入法键盘扩展（`com.tencent.wetype.keyboard` / `wxkb_plugin`）工具栏增强插件。

## 功能
- 工具栏功能图标从默认 **7 个**扩展到 **10 个**
- 图标溢出时**自动缩小、等宽铺满一行**（不再横向滑动）

## 适用环境
- iPhone 12 Pro / iOS 16.6
- Relaxin rootless 越狱（ElleKit / TweakInject）
- 依赖 `mobilesubstrate`（ElleKit 提供）

## 构建
由 GitHub Actions（macOS + Theos）自动编译，产物推送至越狱源：
